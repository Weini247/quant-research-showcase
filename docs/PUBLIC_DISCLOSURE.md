# Public Disclosure Policy

This repository is a curated academic/technical **showcase**, independent from private working repositories.

## Safe to publish after review

- Public research motivation, high-level diagrams and honest development statuses.
- Synthetic computational examples and their tests.
- Sanitized screenshots that contain no private paths, account identifiers, API keys, real licensed rows, sensitive configs, financial exposure or unpublished signals.
- Source citations to publications and official documentation.

## Never copy into this repository without explicit separate clearance

- API keys, `.env`, tokens, credentials or personal account details.
- Commercially licensed/raw datasets or restricted lab/university records.
- Proprietary strategy rules, feature definitions, alpha hypotheses, trained weights or parameter searches.
- Private experiment histories, P&L reports, exchange/venue details or sensitive infrastructure topology.
- Private contract packs and work-chat archives.

## Technical protections are not sufficient by themselves

A `.gitignore` prevents some accidental staging; it **does not** retroactively remove material from Git history. Use a fresh public repository and review all staged files and commit history before each publication. Push protection and secret scanners are additional defenses, not substitutes for review.

## Claims and attribution

Do not present planned features as shipped. No trading profit claims. Use explicit notes where code or writing is AI-assisted, and document personal contributions: problem formulation, scientific checks, design decisions, test interpretation and integration.

No open-source license is assigned to the demonstrator in this starter pack; choose a license explicitly if you want to authorize reuse.
