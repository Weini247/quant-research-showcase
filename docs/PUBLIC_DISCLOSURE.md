# Public disclosure policy

Release 2.1 contains the selected ECB-derived 2018–2019 FX development aggregates, original scientific graphics, newly authored English research prose and an independent public renderer. The fictional accounting demonstration is a separate software example.

The public aggregate scope is model/horizon panel summaries, stored paired interval endpoints, model/horizon/nominal-coverage summaries, complete calendar-quarter/currency/model/horizon means and counts, and measured model-level resources. This does not authorize exporting other measurements.

Exclude credentials, private paths and Git objects, internal conversations/reviews, private core implementations, parameter configurations, model weights, raw market histories, individual measurements and forecast sequences. No EODHD-derived case study, results or empirical graphics are included. Existing rights restrictions remain unchanged.

Figure reproduction is not independent empirical validation. Do not infer economic benefit, trading readiness or a delivered autonomous research engine. No new open-source licence is granted. Public updates must continue the existing public history without transferring private objects. Technical scans supplement, rather than replace, scientific and rights review.
